WP Image Grabber

Collects images from WordPress sites. Everything runs in your browser; nothing is uploaded.

How to use

  1. Open any page on a WordPress site: a shop category, a blog archive, a gallery or a single post.
  2. Click the extension icon (puzzle piece → pin it) or press Alt + Shift + G.
  3. Leave What to collect on Auto-detect, press Scan page, check the thumbnails, then press Download.

Files are named prefix_001.webp, prefix_002.webp… in page order. The defaults are 700 × 700 px at 92% quality; you can change them in the panel and they are remembered.

Images stored on another domain (CDN)

Many sites keep images on a CDN (for example i0.wp.com). Chrome only lets the page read those images if the CDN allows it. If it does not, the grabber can fetch them for you, but that needs permission to access other websites.

The permission is only used to download image files that the page you are on already shows. It never reads other page content, ignores local and private network addresses, and only works on tabs where you opened the panel.

Good to know

  • It uses your normal connection and pauses between requests (400 ms by default). If a site blocks your connection, it cannot load pages either.
  • For infinite-scroll or “load more” pages tick “Scroll this page first”.
  • Non-square pictures are fitted inside the square on white, never stretched.
  • Chrome blocks extensions on chrome:// pages and the Chrome Web Store.
  • Use the images in line with the site’s terms and the owners’ rights.
